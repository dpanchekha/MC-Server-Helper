First-time setup

  1. Install and start the agent.
  2. Open the claim link it prints and sign in or create a playit.gg account.
  3. Claim the agent, then create a Minecraft Java tunnel pointing to your server’s local port, usually 127.0.0.1:25565.
  4. Leave the agent running while friends play. The tunnel remains associated with your account.

Help

A few terms to make server hosting easier to understand.

Memory allocation

This is the maximum amount of RAM Java may use for a server. More players, mods, and larger worlds generally need more memory. Start small and increase it if the server runs out of memory. Do not allocate all of your computer’s RAM.

How servers work

A Minecraft server is a Java program that owns the world, handles player connections, and processes commands. MC Server Helper downloads the server file, runs it without a separate console window, and keeps its files in a separate folder.

Local vs online play

Local play uses this computer. LAN play uses your home network. Online play needs a reachable address, either through router port forwarding or a tunnel service such as playit.gg.

What is playit.gg?

playit.gg is a tunnel service. Its agent runs on the same computer as your server and forwards a public address to the local Minecraft port, so friends can connect without changing router settings.
